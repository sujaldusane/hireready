# \# HireReady

# 

# Track job applications and prepare for interviews with AI-generated, job-specific questions.

# 

# \## Tech Stack

# \- Frontend: React (Vite)

# \- Backend: Flask, PostgreSQL

# \- AI: Claude API with Redis queue and background worker

# \- DevOps: Docker, Docker Compose, GitHub Actions

# 

# \## Status

# 🚧 In development

## Running with Docker

1. Install Docker Desktop.
2. Copy `.env.example` to `.env` and set a password.
3. Run:
```
   docker compose up --build
```
4. Open http://localhost:8080
